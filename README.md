# Keitaro Wrapper

Обёртка над Keitaro на FastAPI, SQLAlchemy и React. Реализована форма создания кампании с выбором гео, оффера, домена, группы и источника. Редактор поддерживает черновики, публикацию и отмену изменений, архивирование и восстановление офферов, закрепление долей.

К названию автоматически добавляется настроенный префикс. Кампания создаётся выключенной, получает поток страны с перенаправлением на Google и второй поток с выбранным оффером (100%), затем включается. При ошибке настройки интерфейс сообщает ID выключенной кампании для проверки в админке. Повторная отправка одного запроса возвращает ранее созданную кампанию. Кнопка «Создать ещё одну» начинает отдельный запрос.

## Требования

- Python 3.11 или новее
- Node.js 22.12 или новее и npm

## Бэкенд

В PowerShell из корня проекта выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.lock.txt
cd backend
Copy-Item .env.example .env
..\.venv\Scripts\python.exe -m alembic upgrade head
..\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Настройки читаются из `backend/.env`. В `KEITARO_BASE_URL` потребуется адрес трекера, в `KEITARO_API_KEY` — API-ключ, в `CAMPAIGN_PREFIX` — префикс `test_фамилия_`. Файл `.env` исключён из Git. Ключ используется только сервером.

Документация приложения доступна по адресу http://127.0.0.1:8000/docs. Проверка состояния — http://127.0.0.1:8000/api/health. Признак `keitaro_configured` проверяет заполненность настроек, фактический доступ проверяется при загрузке справочников.

## Фронтенд

Во втором окне PowerShell из корня проекта:

```powershell
cd frontend
npm ci
npm run dev
```

Откройте адрес, который выведет Vite, обычно http://127.0.0.1:5173. Запросы `/api` перенаправляются в FastAPI на порт 8000.

Проверка сборки:

```powershell
npm run build
```

## Миграции

Команды выполняются из `backend` с установленными зависимостями.

```powershell
..\.venv\Scripts\python.exe -m alembic upgrade head
..\.venv\Scripts\python.exe -m alembic current
..\.venv\Scripts\python.exe -m alembic downgrade -1
```

Миграция 0001 инициализирует историю, 0002 создаёт таблицу черновиков и архивных связей, 0003 добавляет сохранение запросов создания для защиты от повторной отправки.

## Редактор

Введите ID существующей кампании в разделе редактора и нажмите «Загрузить из Keitaro». Перед повторной синхронизацией нужно опубликовать или отменить черновики. «Открыть локальный черновик» восстанавливает сохранённое состояние из SQLite, в том числе после перезапуска приложения.

Добавление, удаление, восстановление и закрепление долей меняют локальный черновик. Жёлтый фон показывает неопубликованный поток. «Опубликовать в Keitaro» применяет состав офферов выбранного потока. «Отменить изменения» возвращает последний сохранённый состав. Офферы, удалённые из потока, сохраняются локально с долей 0% и кнопкой восстановления. Повторная загрузка из Keitaro также архивирует исчезнувшие из трекера связи.

Закреплённые доли сохраняются при пересчёте. Остаток распределяется поровну целыми процентами, остаток округления получают последние офферы. Публикация пустого потока и суммы, отличной от 100%, отклоняется. Если все доли закреплены, их сумма должна быть 100%.

Перед публикацией сверяется актуальный состав офферов Keitaro. При конфликте отмените черновик, загрузите свежие данные и внесите изменения заново. Приложение рассчитано на локальный запуск одним процессом Uvicorn. SQLite хранит редакторские данные в `backend/keitaro.db`; сохраните этот файл, если хотите сохранить черновики и архив.

## Проверки

Из каталога `backend`:

```powershell
..\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Девять автоматических проверок покрывают распределение процентов, закрепление долей, черновики и отмену, архивирование и восстановление, конфликт внешних изменений и повторную отправку создания. Проверки редактора используют имитацию API и отдельную временную базу. Интеграционная проверка требует доступного Keitaro и тестовой кампании с вашим префиксом. Публикация выполняет реальные изменения в трекере.

## Использование ИИ

ИИ-агент помог разобрать ТЗ и демонстрацию, подготовить каркас FastAPI и React, реализовать API-клиент и редактор, проверить сборку, миграции и операции на тестовой кампании. Перед сдачей автору следует ознакомиться с кодом и воспроизвести сценарии проверки.

## Текущие ограничения

- Повтор одного запроса создания возвращает прежний результат. Незавершённая попытка блокирует повтор этого запроса и требует проверки в Keitaro. Новая форма создаёт новый запрос, поэтому после сетевой ошибки сначала проверьте трекер.
- Если создание потоков прервалось, кампания остаётся выключенной; её ID отображается в ошибке.
- Между проверкой внешнего состояния и записью Keitaro возможна внешняя правка. API не предоставляет приложению общей транзакции с трекером.
- Интерфейс использует список офферов, доступных вашему API-ключу. Статистические показатели и графики из видеопримера пока не реализованы.
